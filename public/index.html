What this demonstrates

Per-request quota: the Basic plan allows at most 20 units per request, so a 21-unit request should be rejected.

Shared quota: five-unit Premium actions can use the workspace's 25-unit allowance. Once insufficient units remain, the entire next request is rejected without a partial deduction.

Idempotency: every action receives a unique request ID. The automated test suite also verifies safe retries with the same ID.

Demo data persists in PostgreSQL. This browser interface is for local evaluation, not production authentication.
